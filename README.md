# Mermaid Editor

A single-file, zero-build web app for writing [Mermaid](https://mermaid.js.org/) diagrams with a live preview and one-click export.

**Live**: https://mermaid-editor-seven.vercel.app

## Features

- Live rendering via `mermaid@11` from jsDelivr
- Export to SVG or PNG (1x / 2x)
- Dark UI, Inter + JetBrains Mono

## Local use

Open `index.html` in a browser — no install, no build step.

## Deployment

Hosted on Vercel; pushes to `main` auto-deploy to production.
